Security Architecture Deep Dive

Before payload negotiation begins, a secure asymmetric handshake executes over a WebRTC channel. Every chat session negotiates an entirely temporary, ephemeral Curve25519 public key. This key is cross-signed using the persistent identity Ed25519 key so that Alice is verified. If someone cracks a node at rest in the future, past chat streams cannot be decrypted.

Architecture & Intelligent Network Traversal

How does helucryptic bypass carrier-grade Symmetric NAT setups without running continuous server relays?

STUN & NAT-PMP Fallbacks

If both peers sit behind restrictive firewalls (Symmetric NAT), establishing standard direct pipes is impossible. helucryptic uses local UPnP/NAT-PMP requests to open ports instantly, falling back to STUN traversal mapping.
