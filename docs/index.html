Every message you've ever sent traveled through a computer you don't own.

helucryptic is built on a different assumption.

The signaling server's sole job is to introduce two peers. Once they've found each other, it steps aside. There is no infrastructure that remembers your conversations. No stored messages. No retained metadata. Just two machines, speaking directly.

Step 03 of 05

Connect

Both peers gather network addresses via STUN. ICE candidates are exchanged. A direct UDP path opens between the machines. The server is no longer involved.

Step 04 of 05

Agree

Peers run X25519 ECDH in-channel to derive a shared session key via HKDF-SHA256. Ed25519 cross-signatures authenticate both sides.

X25519 · HKDF-SHA256 · Ed25519
Step 05 of 05

Seal

PASETO v4 with XChaCha20-Poly1305 AEAD seals every packet. A tampered or replayed packet is rejected immediately. Nothing passes in plaintext.

What travels directly

Everything. No exceptions.

Every capability routes peer-to-peer. No feature requires a server to process your content.

Opus audio at 48kHz mono, streamed peer-to-peer. No server transcoding. No third-party relay unless TURN fallback is required.

Primary monitor capture at 15fps with system audio, streamed directly to your peer through encrypted media channels.

File Transfer

Disk-to-disk direct streaming with automatic backpressure management. SHA-256 integrity verification. Files up to 4GB.

Ed25519

Identity Verification

Ed25519 fingerprint comparison with visual status. Green for verified contacts, amber for unverified. Impersonation is structurally prevented.

NAT Traversal

STUN candidate gathering, TURN relay fallback, and NAT-PMP automatic port mapping. Works across restrictive home and enterprise networks.

Architecture Notes

Before any payload is exchanged, both peers perform an in-channel X25519 Diffie-Hellman handshake to derive a shared session key via HKDF-SHA256. The key is unique to this session and never stored or reused. Compromise of a peer's long-term identity key does not expose previous sessions.

Implementation Sample Verified from source
session_key = HKDF(X25519(my_priv, peer_pub), salt, "helucryptic-v1")
Get Running

Up in four commands.

Python 3.11 or later required. PortAudio is bundled on Windows. A pre-built Windows executable is available on the releases page.

# Clone the repository

git clone https://github.com/Cryptic-Mage/helucryptic.git

cd helucryptic

# Create and activate a virtual environment

python -m venv venv

.\venv\Scripts\Activate.ps1

# Install all dependencies

pip install -r requirements.txt

# Start the signaling server, then the client

uvicorn server:app --host 127.0.0.1 --port 8000

python main.py
